# Product Label Cache

This folder stores durable internal product-label references for products that
drive guide recommendations or seasonal planning. It is separate from
`notes/research/`, which is treated as temporary audit work, and separate from
`notes/2026_journal.md`, which records dated work actually performed.

Each product folder should keep:

- a Markdown label summary for future local reference;
- raw label images or PDFs under `source/` when available;
- enough capture metadata to identify where the summary came from.

Before applying any product, verify the current physical label or current
manufacturer label. These cached references are planning aids, not a replacement
for the label in force at application time.

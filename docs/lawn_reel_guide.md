# Lawn Reel Guide

This note explains the Ryobi 2x18V dethatcher/scarifier attachments, how the
common turf terms overlap, and how to decide whether to run either reel on the
Commerce City bluegrass lawn.

## Why this note exists

The terms `dethatcher`, `power rake`, `scarifier`, and `verticutter` are used
inconsistently across brands, countries, and turf communities. For this
property, the more useful distinction is the *type of reel* and what it does to
the lawn surface.

## The main reel types

### 1. Spring tine reel

- The reel with flexible springy metal tines.
- Main job: lift loose surface material such as dead grass, winter matting, and
  light fluffy thatch.
- Least aggressive option.
- Best described as a `dethatcher` or light `power rake`.

### 2. Blade reel

- The reel with spaced fixed metal blades.
- Main job: slice into the turf surface, cut through surface buildup, and open
  the canopy more aggressively than the tine reel.
- Best described as a `scarifier`.
- If run very shallow, it can behave somewhat like a light `verticutter`, but
  it is still more aggressive than a true cleanup pass.

### 3. Dedicated verticut reel

- Not part of the standard Ryobi kit, but sold by some third parties.
- Usually uses narrower, more regular cutting blades.
- Main job: make cleaner vertical slits with less ripping than a typical
  consumer scarifier reel.
- Best fit for overseed prep or light turf grooming, not debris cleanup.

### 4. True core aerator

- Not a reel attachment.
- Uses hollow tines to pull soil plugs out of the ground.
- Main job: relieve compaction and improve air/water movement through the clay
  soil.
- This is what `aeration` means in the strict turf-management sense.
- Neither Ryobi reel is a substitute for true core aeration.

## Naming overlap

### Consumer/homeowner language

- `Dethatcher` often means a spring tine reel.
- `Scarifier` often means a blade reel.
- `Power rake` is often used loosely for either a dethatcher or a scarifier.

### Turf-management language

- `Verticutter` usually means a machine or reel intended to make narrow vertical
  cuts in the turf canopy.
- `Power rake` can imply a more aggressive surface-thatch removal machine.
- `Aerator` normally means a core aerator, not a scarifier reel.

### UK/Europe vs US

- `Scarifier` is more common in UK usage.
- `Dethatcher` and `power rake` are more common in US homeowner language.
- `Verticutting` is common in professional turf language in both markets.

## Thatch vs debris

### Debris / surface matting

- Loose dead grass, winter-killed material, leaves, and matted surface fibers.
- Usually sits on top of the turf canopy.
- Best handled with the spring tine reel, or sometimes by mowing and raking.

### Thatch

- A dense interwoven layer of stems, crowns, stolons, and roots between the
  green grass blades and the soil surface.
- Small amounts are normal.
- It becomes a problem when it acts like a sponge or barrier, making water and
  air movement worse and encouraging shallow rooting.

### Practical trigger

- If the thatch layer is under about `1/2 inch`, leave it alone unless there is
  a specific overseed-prep reason to open the surface.
- If it is over about `1/2 inch`, intervention becomes more reasonable.

## What each tool is good for on this lawn

### Spring tine reel

Use for:
- Light spring cleanup.
- Lifting winter matting.
- Pulling up loose dead material.

Avoid relying on it for:
- Clay compaction relief.
- Deep thatch correction.
- Routine scheduled use without visible need.

### Blade reel

Use for:
- More aggressive surface opening.
- Seedbed prep before overseeding.
- Condition-based thatch reduction when surface buildup is real.

Avoid using it:
- On a lawn that is still mostly dormant.
- As a routine spring operation just because the calendar says so.
- As a replacement for core aeration.

### Core aeration

Use for:
- Annual clay-soil relief.
- Improving infiltration and oxygen movement.
- Late-summer / early-fall renovation work.

This remains the highest-value lawn renovation tool for this property.

## Spring vs fall decision process

### Spring

Run the spring tine reel only if one or more of these are true:
- The lawn has visible winter matting or loose dead material.
- The surface looks matted enough that green-up is being smothered.
- A light cleanup pass can be done without digging into soft soil.

Avoid the blade reel in spring unless:
- The lawn is clearly active and growing.
- There is a real surface-buildup issue.
- You have a specific reason stronger than general maintenance.

For this property, spring is usually a cleanup window, not a renovation window.

### Late summer / early fall

This is the main decision window for more aggressive work.

Use this order:
1. Check for surface debris vs real thatch.
2. If it is mostly loose debris or matting, use the spring tine reel.
3. If you want overseed prep or light slicing, use a shallow blade-reel pass or
   a dedicated verticut reel.
4. If compaction / infiltration is the real issue, prioritize core aeration.
5. If overseeding, pair surface opening with seed and irrigation rather than
   doing aggressive reel work alone.

## Property-specific recommendation

- Do **not** run either reel on a fixed annual schedule just to "control
  thatch."
- Treat both reels as condition-based tools.
- Use the spring tine reel for cleanup.
- Use the blade reel mainly for overseed prep or confirmed surface-buildup
  problems.
- Keep true core aeration as the default annual late-summer soil-relief step for
  the bluegrass lawn.
